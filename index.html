02 / Project

《馍饼店》横屏经营小游戏

独立完成的完整游戏项目 · Canvas 原生实现 · 零第三方依赖 · 40 个测试全部通过

以中国早点摊为主题的经营小游戏：13 道菜品、4 类厨具、16 位街坊顾客，三块案板并行制作，揉面、加馅、塑形、翻面、切块都由手势完成；画面里的人和食物全部用 Canvas 代码绘制，没有任何图片素材，也不依赖网络。
约 1800 行核心源码零第三方依赖40 个 Node 测试单文件构建 · 微信小游戏入口
在线试玩 ↗
核心玩法逻辑同时兼容浏览器与 Node 双环境，所以玩法、手势、库存、定价、存档这些系统都能在没有浏览器的环境里自动跑测试；另外写了构建脚本把多模块源码打包成 149 KB 的单文件 HTML，双击就能玩。（源码暂未公开，可在面试中演示。）

04 / Embedded Project

STM32 健康监测蓝牙终端

个人兴趣项目 · 从原理图接线到 1045 行应用层 C 代码全部独立完成

一块 STM32F103C8T6 核心板 + MAX30102 + MPU6050 + 0.96 寸 OLED + HC-08 蓝牙，做成的可穿戴健康监测终端：本地采集心率血氧与姿态、越界就地声光报警，同时按帧把数据推给手机。
STM32F103 · Cortex-M3MAX30102 心率血氧MPU6050 跌倒检测HC-08 蓝牙透传Flash 配置持久化
1045 行应用层 C 代码（src/main.c）：PPG 波形滤波计算心率血氧、DMP 姿态角判定跌倒、多页面四键 UI、阈值掉电不丢、MANUAL/AUTO 双工作模式——非课程作业、非厂商例程改造。

05 / Embedded Project

嵌入式 Linux 智能家居控制终端

企业实训项目 · 纯 C 帧缓冲直绘 UI · 中控 + STM32 从机 + Ubuntu 语音三层架构

在嵌入式 Linux 开发板上用纯 C 写出智能家居中控：800×480 电阻触摸屏、帧缓冲（mmap）直绘界面，串起「嵌入式中控 + STM32 从机（3 路 LED / 血压 / 心率，串口通信）+ Ubuntu 语音识别（TCP socket）」三层。
嵌入式 Linux纯 C · 无 GUI 框架帧缓冲 mmap 直绘触摸去抖分发串口 / Socket 通信
BMP 解码、页面状态机、触摸热区、语音命令分发全部手写；欢迎页 → 开机进度条 → 主页四卡片（相册 / 语音控制 / 留言器 / 灯光控制），每个页面独立循环、返回热区。
